พิมพ์ตัวเลขเพื่อเปิดอ่านข้อความ

คืองี้ใช่ไหม คือเมื่อวานก่อนอ่ะเราบ่นกับพ่อแม่ว่า เราอยากได้รถ และทีนี้พ่อแม่เราก็พูดว่า “เดี๋ยวพรุ่งนี้พาไปซื้อรถนะ” และทีนี้วันนี้เราก็มาซื้อรถจริงๆ มีหลายคันมาก เลือกไม่ถูกเลยแหละ แบบมันหลายคันจริงๆ แต่เรามีคันที่ชอบนะ คันถึงเธอทุกวิด “คิดถึงเธอทุกวัน” >< 🩵
